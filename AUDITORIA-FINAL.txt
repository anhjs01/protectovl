YOUTUBE
- Los IDs actuales se validaron sintácticamente con el patrón [-_A-Za-z0-9]{11}.
- La presencia de un ID válido no garantiza que YouTube permita la inserción: un video puede ser privado, eliminado, restringido o tener la inserción desactivada.
- Los enlaces concretos de la lista se contrastaron con resultados web disponibles durante esta revisión cuando fue posible.
- No se afirma que un video de YouTube permanecerá disponible indefinidamente.

AUDIO LOCAL
- El nombre del archivo local es parte de la configuración del catálogo.
- Ejemplo: “Perfect - Ed Sheeran.mp3” debe estar en musica/ con exactamente ese nombre.
- El reproductor busca coincidencia por título y artista y usa el archivo local como respaldo.
- Los archivos deben obtenerse de fuentes donde el usuario tenga derecho a usarlos y alojarlos.

GITHUB PAGES
- GitHub Pages publica sitios de hasta 1 GB y tiene un límite flexible de ancho de banda de 100 GB/mes según la documentación vigente.
- GitHub bloquea archivos individuales de más de 100 MiB en repositorios Git normales.
- Git LFS no se puede usar con sitios GitHub Pages.
- Por eso se recomienda mantener los MP3 comprimidos y controlar el tamaño total del sitio.
