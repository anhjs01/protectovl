LISTA DE MÚSICA — CALENDARIO 365
================================

OBJETIVO
Esta lista es para construir la biblioteca LOCAL del reproductor. El nombre de archivo indicado en cada línea es el nombre exacto que el reproductor espera dentro de la carpeta musica/.

IMPORTANTE SOBRE YOUTUBE
- Un enlace de YouTube puede funcionar hoy y dejar de permitir inserción mañana.
- Un video puede ser corto, privado, eliminado, restringido por región o tener la inserción desactivada.
- Por eso la copia LOCAL es el respaldo estable.
- Los enlaces marcados como exactos fueron contrastados durante esta revisión; no constituyen una garantía futura de reproducción incrustada.

IMPORTANTE SOBRE ARCHIVOS LOCALES
- Descarga/obtén los archivos únicamente de fuentes en las que tengas derecho a usarlos y alojarlos.
- El proyecto NO necesita que descargues las 200+ canciones. Empieza por las que quieras.
- Guarda cada archivo exactamente con el nombre indicado.
- Formato recomendado: MP3 de 128–192 kbps para mantener el sitio liviano. Evita WAV/FLAC para GitHub Pages salvo que tengas una razón concreta.
